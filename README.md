# Plus Smart Home Tech

**Комплексная платформа для управления умным домом с интегрированной экосистемой интернет магазина.**  
Система объединяет IoT-управление устройствами, телеметрию, автоматизацию сценариев и полноценную торговую платформу для покупки умных устройств и аксессуаров.  

Template repository для проекта Plus Smart Home Tech.

## 🎯 Цель проекта
- Практика разработки приложений на микросервисной архитектуре с использованием Spring Boot
- Изучение и практика работы с Apache Kafka
- Практика работы с различными протоколами связи (HTTP, gRPC, Kafka)
- Освоение различных форматов сериализации данных (Avro, Protocol Buffers)
- Изучение паттернов микросервисной архитектуры (Configuration Server, Service Discovery, API Gateway, Circuit Breaker)
- Практика реализации сложных бизнес-процессов

## 📋 Функциональность
- Сбор, агрегация и анализ телеметрических данных с IoT-устройств в реальном времени
- Автоматизация сценариев умного дома на основе данных с датчиков
- Полноценный интернет-магазин умных устройств и аксессуаров
- Управление складом, заказами, платежами и доставкой
- Корзина покупок и управление товарами
- Централизованная конфигурация и обнаружение сервисов
- API-шлюз для единой точки входа в систему
- Circuit Breaker для снижения нагрузки на систему

- **Язык:** Java 21

## 🏗️ Архитектура и ключевые компоненты

### Микросервисная архитектура

Для удобства приложение разбито на несколько ключевых модулей:

| Модуль                     | Сервис             | Назначение                                                                  |
|----------------------------|--------------------|-----------------------------------------------------------------------------|
| **Коммерция (Commerce)**   | Shopping Store     | Каталог товаров и управление продуктами                                     |
|                            | Shopping Cart      | Корзина покупок пользователей                                               |
|                            | Order Service      | Управление заказами и координация бизнес-процессов                          |
|                            | Payment Service    | Обработка платежей и расчет стоимости                                       |
|                            | Warehouse Service  | Управление складом и резервирование товаров                                 |
|                            | Delivery Service   | Расчет стоимости и организация доставки                                     |
| **Инфраструктура (Infra)** | Config Server      | Централизованное управление конфигурациями                                  |
|                            | Discovery Server   | Регистрация и обнаружение сервисов                                          |
|                            | Gateway            | Единая точка входа и маршрутизация запросов                                 |
| **Телеметрия (Telemetry)** | Collector Service  | Прием данных от датчиков и хабов через gRPC                                 |
|                            | Aggregator Service | Агрегация и обработка потоковых данных из Kafka                             |
|                            | Analyzer Service   | Анализ данных и отправка хабам команд на выполнение сценариев автоматизации |

### Основные сервисы

Каждый сервис имеет собственную базу данных и взаимодействует с остальными с помощью Feign-клиентов

#### 1. **Сервис телеметрии (Collector Service)**
- gRPC сервер для приема событий от IoT-устройств
- Обработка событий хабов и датчиков через фабрики обработчиков с использованием паттерна _стратегия_
- Отправка данных в Kafka для дальнейшей обработки

#### 2. **Сервис агрегации (Aggregator Service)**
- Агрегация событий от датчиков в снимки состояний
- Отправка готовых снимков в Analyzer Service через Kafka

#### 3. **Сервис анализа (Analyzer Service)**
- Анализ снимков данных в реальном времени
- Проверка условий сценариев автоматизации
- Отправка команды хабам на выполнение действий через gRPC клиент
- Использование фабрик и паттерна _стратегия_ для проверки условий разных типов

#### 4. **Сервис магазина (Product Service)**
- Полный цикл CRUD для продуктов
- Управление каталогом товаров с категоризацией
- Управление состоянием товаров (активен, деактивирован)
- Управление состоянием количества товара (закончился, мало, достаточно, много)
- Пагинация и фильтрация по категориям

#### 5. **Сервис корзины (Shopping Cart Service)**
- Создание и управление корзинами пользователей
- Добавление/удаление товаров с проверкой наличия
- Изменение количества товаров в корзине
- Интеграция с Warehouse для проверки доступности

#### 6. **Сервис заказов (Order Service)**
- Координация всего процесса заказа
- Управление статусами заказа (новый, оплачен, собран, доставляется, доставлен, завершен итд)
- Интеграция с Payment, Delivery, Warehouse и Shopping Cart сервисами
- Обработка возвратов товаров

#### 7. **Сервис платежей (Payment Service)**
- Расчет полной стоимости заказа с учетом стоимости товаров, доставки и НДС
- Обработка успешных и неудачных платежей
- Интеграция с Order для обновления статусов оплаты
- Расчет стоимости товаров на основе цен из магазина

#### 8. **Сервис склада (Warehouse Service)**
- Управление складскими запасами
- Резервирование товаров под заказы
- Расчет характеристик заказа (объем, вес, хрупкость)
- Обработка возвратов

#### 9. **Сервис доставки (Delivery Service)**
- Расчет стоимости доставки с учетом множества факторов (расстояние, хрупкость, габариты, вес итд)
- Управление адресами отправки и получения
- Интеграция со складом для отправки товаров
- Интеграция с сервисом заказов для обновления статусов доставки
